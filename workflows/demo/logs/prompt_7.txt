## What went wrong

The only failures are in the `decreasing_by` blocks of `mergesort` and `mergesort_sorted` (the same mistake, repeated four times).

After `simp_wf`, Lean has already *normalized* the goal: the `List.length` of the literal cons-cells has been computed and the strict inequality `a < b` has been unfolded to its `Nat.succ`-form. So the goal is no longer literally

```
(split (x :: y :: rest)).1.length < (x :: y :: rest).length
```

but the simp-normal form

```
(split (x :: y :: rest)).1.length ≤ rest.length + 1
```
